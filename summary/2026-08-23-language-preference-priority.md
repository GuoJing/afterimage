# 用户语言偏好优先级交接

- 用户通过全站语言菜单、文章语言按钮或页面语言按钮选择语言后，选择结果继续保存在 `afterimage.locale` Cookie 中。
- 文章或页面已有、但未列入全站 `BLOG_LOCALES` 菜单的翻译语言，也可以通过内容页语言按钮选中并记住。
- 公开 HTML 页面按“用户已选语言 → URL 指定语言 → 站点默认语言”的顺序解析语言。
- 当文章、独立页面、首页或归档页 URL 的语言与用户已选语言不一致时，使用 `302` 临时重定向到用户语言对应的 URL，确保地址、正文、canonical 和分享信息保持一致。
- 用户尚未明确选择语言时，文章和页面继续以 URL 中的语言为准；首页和归档则使用 `lang` 参数，没有参数时使用 `DEFAULT_LOCALE`。
- 浏览器 `Accept-Language` 不再覆盖页面默认语言，只有用户主动选择才会形成最高优先级偏好。
- RSS、Markdown 原文、Sitemap、llms.txt 等机器读取端点不读取用户语言 Cookie，继续严格遵循各自 URL 的语言语义。
