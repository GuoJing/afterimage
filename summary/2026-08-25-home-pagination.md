# 首页文章分页

- 首页每页显示 10 篇已发布文章，按发布时间和文章 ID 倒序稳定排列。
- 只有第一页的第一篇文章显示 Markdown 全文；第一页其余文章及第二页之后的全部文章只显示标题、元信息与摘要。
- 分页只显示“上一页”和“下一页”，第一页没有上一页，最后一页没有下一页；中文、英文、日文提供对应文案和无障碍标签。
- 默认语言分页 URL 为 `/?page=2`，其他语言为 `/?lang=en&page=2`、`/?lang=ja&page=2`；用户已选择语言时仍以用户选择优先，并保留页码。
- 每一页都有独立 canonical、hreflang、x-default 以及 `rel=prev/next`，非法页码和超出范围的页码返回 404。
- 首页介绍只保留在第一页，后续分页专注显示文章摘要列表。
