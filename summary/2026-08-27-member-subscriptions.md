# 会员订阅与文章邮件推送

## 已完成

- 新增仅限登录会员访问的 `/subscribe` 页面，支持中文、English、日本語。
- 三个开关默认开启：新文章推送、Newsletter、活动推送；数据库只记录会员主动关闭的类别，重新开启会删除退订记录。后两项目前仅保留偏好，不参与发信。
- 接收邮箱只从当前登录会员读取，客户端不能指定或替换收件地址。
- 会员保存订阅时同时保存当前界面语言，文章邮件优先使用该语言，缺少翻译时回退 `DEFAULT_LOCALE`，再回退任意现有翻译。
- 后台文章列表为每篇文章增加独立“推送”入口和已发送/订阅人数。
- 推送页展示所有开启新文章推送的正常会员、送达状态、成功次数和最近发送时间。
- 全量推送仅发送给尚未成功收到当前文章的会员；成功记录持久化，进程重启或重复点击都不会重复发送。
- 单用户支持“强制发送”，允许在已经送达后再次发送；没有全员强制发送入口。
- 草稿、未配置 SMTP、并发重复提交都会被拒绝。
- 邮件模板包含文章标题、摘要、Markdown 正文、阅读全文链接、订阅设置链接以及 copyright，视觉风格与公开文章页保持一致。

## 数据库

启动时由 `lib/subscription-store.js` 自动执行 `CREATE TABLE IF NOT EXISTS`，不需要手动迁移：

- `user_subscription_settings`：只保存会员用于邮件的界面语言。
- `user_subscription_opt_outs`：只保存会员主动关闭的订阅类别。
- `post_email_deliveries`：文章与会员维度的成功时间、成功次数、最近收件地址和失败状态。

三张表均使用外键级联；删除会员或文章时，对应设置、退订及投递记录会自动删除。没有偏好记录的正常会员按默认订阅处理。

## 主要文件

- `server.js`：公开订阅路由、后台推送路由、语言回退与发送编排。
- `lib/subscription-store.js`：订阅偏好及投递记录的 SQLite 封装。
- `lib/post-email.js`：三语文章邮件模板与 SMTP 调用。
- `views/subscribe.ejs`：会员订阅页面。
- `views/admin/post-delivery.ejs`：后台逐篇推送页面。
- `test/subscription-store.test.js`、`test/post-email.test.js`：持久化去重和邮件模板测试。

## 运维说明

- 沿用现有 `MAIL_ENABLED=1`、SMTP 和 `SITE_URL` 配置，没有新增环境变量。
- 部署拉取代码并重启 Node.js 服务即可自动建表。
- 投递失败的真实错误只写服务端日志，数据库和后台只显示通用失败状态，避免泄露 SMTP 信息。
