# Gallery 后台皮肤设置交接

## 已实现

- 将原来的“扩展设置（JSON）”替换为可视化“Gallery 皮肤”配置器。
- 提供四种详情页皮肤：`masonry` 瀑布流、`grid` 平铺网格、`fade` 渐隐画廊、`justified` 智能拼接。
- 每种皮肤使用独立参数面板，切换皮肤时只显示当前皮肤相关参数。
- 管理员选择仍保存到 `galleries.settings_json`，结构统一为 `{ "theme": "...", "options": { ... } }`。
- 服务端按照皮肤白名单清理并验证参数，不接受未知皮肤、非法选项或超范围数字。
- 旧 Gallery 的 `{}` 或无法识别的设置在后台读取时自动使用默认瀑布流，不需要修改数据库。

## 皮肤参数

- 瀑布流：桌面列数、平板列数、图片间距、是否显示照片描述。
- 平铺网格：桌面列数、平板列数、图片间距、画幅比例、裁切铺满/完整显示。
- 渐隐画廊：是否自动播放、停留时间、渐变时间、图片适配、是否显示缩略图导航。
- 智能拼接：目标行高、最大行高、图片间距、末行对齐、是否显示照片描述。

## 数据说明

皮肤设置本身没有增加 SQLite 字段。后续公开详情页已经直接读取 `settings_json` 决定渲染器和对应参数；URL 功能另行增加了 `galleries.slug`。
